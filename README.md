# ShiduchimApp

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.31.

## Development server

Install dependencies and set your Gemini API key in the current PowerShell session:

```powershell
npm install
$env:GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
npm start
```

Open `http://localhost:4200/`. The start script runs the local chat API and Angular development server together. Keep the API key private; do not commit it to the repository.
